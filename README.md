📝 Focus Flow – To-Do List Web App

📌 Internship Task

Synent Technologies – Web Development Internship
Task 5: To-Do List Web App


🎯 Objective

Build a task management web application that allows users to manage daily tasks efficiently with persistent storage.


🚀 Features

Core Features

   * Add new tasks
   * Delete tasks
   * Mark tasks as completed
   * Data stored using localStorage
   * Tasks persist after page refresh

Additional Features (Advanced)

   * Edit tasks (inline editing)
   * Task statistics (Total / Completed / Pending)
   * Filter tasks (All / Pending / Completed)
   * Clear completed tasks
   * Add task using Enter key
   * Modern UI with glassmorphism design
   * Fully responsive layout



  Technologies Used

    * HTML5
    * CSS3
    * JavaScript (DOM Manipulation & localStorage)



 Project Structure


├── index.html
├── style.css
├── script.js
└── README.md




 How It Works

* Tasks are stored in the browser using localStorage
* Each task has:

  * Unique ID
  * Task text
  * Completion status
  * On page load, tasks are retrieved and displayed automatically


How to Run

1. Download or clone the repository
2. Open index.html in any browser
3. Start adding your tasks 


 Output

* Tasks remain saved even after refreshing the page
* Users can manage tasks efficiently with a clean UI
